# Iosevka

Couchview bundles subsetted WOFF2 builds of the Iosevka typeface version
34.8.0 for browser terminal text. The subsets retain the character repertoire
previously bundled with Couchview where Iosevka provides the same characters.
The upstream project and release are available at:

- https://github.com/be5invis/Iosevka
- https://github.com/be5invis/Iosevka/releases/tag/v34.8.0
